# 代码评测测试用例格式指南

本文档说明代码评测系统支持的测试用例输入格式。

## 概述

代码评测系统使用 `generate_judge0_code()` 函数将用户代码包装成完整程序，在 Judge0 沙箱环境中执行。系统支持多种输入格式，包括标准 JSON 和 Python 字面量。

## 解析顺序

系统按照以下优先级尝试解析输入数据：

1. **JSON 解析**（优先） - 标准格式，推荐用于新测试用例
2. **Python 字面量解析** - 支持 Python 特有类型（元组、集合等）
3. **逗号分割 Fallback** - 兼容简单题目

## 支持的格式

### 1. JSON 格式（推荐）

**列表（数组）**
```json
[1, 2, 3]
["hello", 5]
[[1, 2], [3, 4]]
```

**对象（字典）**
```json
{"n": 5, "s": "hello"}
{"nums": [1, 2, 3], "target": 9}
```

**字符串**
```json
"hello world"
```

**数字**
```json
42
3.14
```

**布尔值（JSON 格式）**
```json
true
false
```

**null**
```json
null
```

### 2. Python 字面量格式

**元组**
```python
(1, 2, 3)
[(1, 2, 3), 2]      # 列表包含元组
((1, 2), (3, 4))    # 元组包含元组
```

**集合**
```python
{1, 2, 3}
{"a", "b", "c"}
```

**布尔值（Python 格式）**
```python
True
False
```

**None**
```python
None
```

**混合类型**
```python
[(1, 2, 3), True, None, "text"]
{"tuple": (1, 2), "set": {1, 2, 3}}
```

### 3. 简单字符串 Fallback

对于既不是 JSON 也不是 Python 字面量的输入，系统会按逗号分割：

```
hello, world  →  ["hello", "world"]
```

## 参数解包规则

解析后的数据会根据类型自动解包为函数参数：

| 解析结果类型 | 解包方式 | 示例 |
|------------|---------|------|
| 列表/元组 | 位置参数解包 | `[1, 2]` → `solve(1, 2)` |
| 字典 | 关键字参数解包 | `{"a": 1, "b": 2}` → `solve(a=1, b=2)` |
| 其他类型 | 单个参数 | `"hello"` → `solve("hello")` |

## 示例题目

### 示例 1：两数之和

**函数定义**
```python
def two_sum(nums, target):
    # 实现代码
    pass
```

**测试用例**
| 输入 (input_data) | 调用方式 |
|------------------|---------|
| `[[2, 7, 11, 15], 9]` | `two_sum([2, 7, 11, 15], 9)` |
| `{"nums": [2, 7, 11, 15], "target": 9}` | `two_sum(nums=[2, 7, 11, 15], target=9)` |

### 示例 2：元组访问

**函数定义**
```python
def access_tuple(t, index):
    return t[index]
```

**测试用例**
| 输入 (input_data) | 调用方式 |
|------------------|---------|
| `[(1, 2, 3), 2]` | `access_tuple((1, 2, 3), 2)` |
| `[(10, 20, 30, 40), 0]` | `access_tuple((10, 20, 30, 40), 0)` |

### 示例 3：集合操作

**函数定义**
```python
def set_operation(s):
    return len(s)
```

**测试用例**
| 输入 (input_data) | 调用方式 |
|------------------|---------|
| `{1, 2, 3}` | `set_operation({1, 2, 3})` |
| `{"a", "b", "c"}` | `set_operation({"a", "b", "c"})` |

### 示例 4：布尔值判断

**函数定义**
```python
def check_flag(flag):
    return not flag
```

**测试用例**
| 输入 (input_data) | 调用方式 |
|------------------|---------|
| `True` | `check_flag(True)` |
| `False` | `check_flag(False)` |

## 安全性说明

系统使用 `ast.literal_eval()` 安全地解析 Python 字面量，该函数只解析字面量，不执行任意代码。

**安全的行为**：
- 恶意代码如 `__import__('os').system('ls')` 会被当作普通字符串处理，不会被执行
- 表达式如 `len([1, 2, 3])` 会被拒绝或当作字符串处理

**不支持的类型**：
- 函数调用：`len([1, 2, 3])`
- 算术表达式：`1 + 2`
- 自定义类实例
- Lambda 表达式

## 最佳实践

1. **优先使用 JSON 格式** - 标准、跨语言、解析速度快
2. **仅在需要时使用 Python 字面量** - 如元组、集合等 JSON 不支持的类型
3. **保持测试用例简洁** - 避免过于复杂的嵌套结构
4. **验证边界情况** - 包括空列表、空字符串、None 等

## 输出格式

用户函数的返回值会根据类型自动处理：

| 返回类型 | 输出方式 |
|---------|---------|
| 字典/列表/元组/布尔/None | JSON 序列化输出 |
| 字符串/数字 | 直接输出 |

示例：
```python
return [1, 2, 3]      # 输出：[1, 2, 3]
return {"a": 1}       # 输出：{"a": 1}
return True           # 输出：true
return 42             # 输出：42
return "hello"        # 输出：hello
```
